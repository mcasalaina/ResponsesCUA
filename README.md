# ResponsesCUAPrPr

Welcome to the Responses API + CUA Private Preview!

In this repo you will find 3 folders:
responses_samples that contains basic samples for the Responses API. These include conversation threading, tool usage, and use of the new CUA model.
Two folders called cua_scripts_vnc and local_cua_scripts_vnc. These are specific for running the CUA model on a VM, as well as a local machine.
