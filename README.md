# ResponsesCUAPrPr

Welcome to the Responses API + CUA Private Preview!

In this repo you will find 2 folders:
* `responses_samples` that contains basic samples for the Responses API. These include conversation threading, tool usage.
* `cua` contains a sample to run the CUA model with either a remote VNC machine or a local machine.

Please set the environment variable BASE_URL to the your sub url. Should be something like https://subname-region.openai.azure.com/openai/responses
Please set the environment variable API_VERSION to the api version. Should be 2024-12-01-preview
Please set the environment variable OPENAI_API_KEY to your API key
